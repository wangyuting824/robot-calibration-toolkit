# 验收范围与输出解释

所有阈值在 acceptance.yaml 或限位规格中明确配置；空值产生 unverified，不提供看似通用的 mm/deg 合格值。

- 结构检查：连接有效性、唯一父节点、URDF 树、单位、数值、轴单位向量、关节限位、惯性物理条件和确认状态。
- 参考拟合：输出 scale、offset 和残差；需要独立验证，不等于已改变驱动器参数。
- 限位：核对记录与明确规格，统计散布和重复性；不创建新的机械极限。
- 运动学：使用独立数据，报告位置与方向误差。标定雅可比数值满秩不等于实体精度达标。
- USD：检查静态关节定义、坐标/轴/锚点、单位及质量惯性。运行时 FK、碰撞间隙和动态响应另行验证。
- 动力学：相同实际输入、初始条件和负载，按已声明公共时钟比较；缺少需要的力矩或接触观测时阻止相应验收。

最终打包检查当前文件哈希与报告输入是否一致。kinematics 阶段要求结构、模型、真实限位记录和真实运动学验证；dynamics 阶段额外要求 USD 检查与声明指标范围内的真实/仿真对比。数据和报告来源仍须项目负责人核对，自动门禁不能证明填写资料本身真实。

本地逆动力学和接触拟合是有适用范围的模型，不应将某个关节、某个负载或某一接触工况上的拟合通过推广为整机全部工况已对齐。
